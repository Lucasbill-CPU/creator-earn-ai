# creator-earn-ai

CreatorEarn AI is a lightweight Expo mobile app designed to help creators discover and evaluate startup ideas with revenue estimates, progress tracking, and premium credit packs.

Features
- Save and organize business/app ideas
- Readily score opportunity and viability
- Estimate revenue with quick formula updates
- Track idea progress from concept to testing
- Purchase extra credits for deeper analysis
- Ready for Expo / EAS packaging and App Store prep

Quick start
1. Install dependencies:
   npm install
2. Launch the app:
   npm start
3. Run on simulator, emulator, or physical device

Production notes
- This is an MVP app using local storage for idea persistence.
- For real purchases, replace the demo credit purchase flow with RevenueCat or App Store/Google billing.
- For App Store distribution, use EAS Build and App Store Connect with a proper signing profile.
